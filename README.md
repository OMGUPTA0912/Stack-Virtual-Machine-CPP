# Stack Virtual Machine & Compiler (C++)

This project implements a custom Stack-Based Virtual Machine (CVM) and a corresponding Compiler built entirely in C++. It parses custom source code, compiles it into bytecode, and executes it on the virtual stack architecture.

## 🚀 How to Build

This project uses **CMake** for building. Ensure you have CMake and a C++ compiler (like g++ or MSVC) installed.

1. Clone the repository:
   ```bash
   git clone https://github.com/OMGUPTA0912/Stack-Virtual-Machine-CPP.git
   cd Stack-Virtual-Machine-CPP
   ```

2. Create a build directory and compile:
   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ```
   *(Note for Windows users: You can use `cmake --build .` instead of `make`)*

This will generate the main executable.

## 💻 How to Run (Demo)

We have provided sample `.cvm` files in the root directory (e.g., `test.cvm` and `loop_test.cvm`).

To compile and run a program on the Virtual Machine, pass the source file to the executable:

```bash
./cvm ../test.cvm
```
*(Replace `./cvm` with the exact name of the executable generated by CMake, such as `./StackVM` depending on the CMakeLists.txt configuration).*

### Expected Output
The program will tokenize the source, parse it into an Abstract Syntax Tree (AST), compile it into opcodes, and the Virtual Machine will execute the bytecode, printing the results of the stack operations to the console.

## 📁 Project Structure
- `src/Lexer.cpp` & `Parser.cpp`: Handles reading the raw code and building the AST.
- `src/Compiler.cpp`: Translates the AST into bytecode instructions.
- `src/VM.cpp`: The core Stack Virtual Machine that executes the instructions.
- `src/main.cpp`: The entry point that ties the pipeline together.
